# Abstract

## Exam Regulation Assistant Using RAG with Guardrails

The Exam Regulation Assistant Using RAG with Guardrails is an AI-powered system designed to help students understand examination rules and regulations easily. Students often face difficulties finding accurate information about attendance requirements, examination procedures, supplementary examinations, revaluation and other academic rules.

The proposed system uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from official examination documents and generate answers to students' questions in natural language. Guardrails are implemented to improve reliability by checking whether responses are relevant to the available information and preventing unsupported answers. If the required information is unavailable in the documents, the system can inform the student instead of generating an unverified response.

The main objective of this project is to provide a simple, accessible and reliable platform for answering examination-related queries. It aims to reduce confusion, save students' time and improve access to official examination information.

**Keywords:** Artificial Intelligence, Retrieval-Augmented Generation, Large Language Models, Guardrails, Examination Regulations, Question Answering System.
